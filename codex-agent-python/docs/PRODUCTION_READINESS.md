## 2. 进入测试环境前

- [ ] 准备独立测试数据库、CODEX_HOME、模型认证、MCP 和测试 OMS，固定代码/模型版本。
- [ ] 应用正确数据库迁移；旧系统升级按[执行契约](EXECUTION_CONTRACT.md)停写、排空并协调 Python/Java。
- [ ] 为各调用方向分配独立密钥，关闭终端用户访问内部执行接口。
- [ ] 使用干净的 CODEX_HOME；核对有效配置，禁止未经验证的全局跨会话记忆混入多租户服务。
- [ ] 确认测试业务数据和真实调用路径。只读 fixture 不支持取消写入，不能冒充完整 OMS。

## 3. 上线前必须闭环的事项

| 优先级 / 事项 | 当前缺口 | 通过标准 | 负责角色 |
|---|---|---|---|
| P0 真实业务链路 | 没有已归档的端到端验收 | 查询、澄清、申请、拒绝、批准后原会话继续、结果核实全部通过 | Agent + 业务团队 |
| P0 OMS 原子幂等 | 当前只传固定 key | 并发/重放/提交后断线/进程崩溃均只有一次业务效果；冲突 key 拒绝；事件去重 | OMS 团队 |
| P0 身份与资源权限 | 受控后端 Header 模式，企业身份尚未接通 | BFF 派生身份；伪造角色、跨租户/资源访问被拒；明确审批人权限 | 业务 + 安全团队 |
| P0 文件/网络/记忆隔离 | 应用限制已有，部署边界未验收 | 不能读写别的用户数据；不能通过本地能力、共享 memory 或非授权网络访问旁路 | 安全 + 运维 |
| P0 凭据管理 | 未完成正式轮换方案 | 安全注入、轮换演练、日志/Trace 不泄露密钥与敏感业务数据 | 运维 + 安全 |
| P0 状态恢复 | 尚无 crash/recovery 实验 | PG 映射和 Codex 状态匹配，重启能恢复；在途业务先对账，无盲目重新执行 | Agent + 运维 |
| P0 真实安全 Eval | 实现有门禁，缺真实实验 | 全部关键用例有终态、无跳过、三个确定性评分均为 1；攻击 fixture 路由确认 | Agent + QA |
| P0 可复现发布 | 依赖部分为范围，无完整发布流水线 | 固定依赖/镜像/模型配置；构建、扫描、迁移和回滚过程可重复 | 开发 + 运维 |
| P1 发布与长连接 | 尚无实际部署验收 | 停准入→排空→停止旧 Runtime→独占盘启动；代理缓冲/超时/断线行为正确 | 运维 + 前端 |
| P1 备份与恢复 | 配置持久目录不等于灾备 | PostgreSQL + CODEX_HOME 备份恢复演练；确定 RPO/RTO 和一致性/对账流程 | 运维 |
| P1 容量与告警 | 无已确认的容量/SLO 证据 | 实测吞吐/延迟/错误率；并发、503、DB 池、工具失败、模型成本有告警 | 开发 + 运维 |
| P1 审批产品体验 | 没有审批 UI 与业务操作审计验收 | 展示规范参数/有效期；权限和过期处理明确；结果不明不误报成功 | 产品 + 业务团队 |

P0/P1 是建议实施顺序，不表示 P1 可以不验收就全量上线。每次发布应明确适用项、负责人和证据。

## 4. 建议执行顺序

1. 按[上手指南](GETTING_STARTED.md)完成读链路，确认模型实际调用工具。
2. 接测试 OMS，验收审批到取消的完整链路与固定 key。
3. 跑 LangSmith 基线与恶意工具数据用例，按失败所属层修复 Skill/Tool/Policy。
4. 验证身份、文件、网络和跨会话记忆边界。
5. 完成数据库/状态盘恢复、发布排空、容量与监控。
6. 证据齐全后决定有限灰度，记录回滚条件与负责人。

所有真实模型结果必须附模型 ID、代码 SHA、题库版本及环境摘要。Mock、fixture 声明、模型声称“成功”和单次正常运行都不能替代事务/权限验收。

## 5. 作为公司标准底座还需要什么

- 将已稳定的接口和授权契约版本化，建立兼容升级规则；SDK 私有适配集中维护。
- 用第二个真实业务验证复用边界，再抽公共包；当前无需为平台愿景重写循环。
- 定义业务接入模板：身份、工具 Schema、写操作幂等、Skill、题库、告警与运维手册。
- 如果需要长期记忆，先定义 tenant/user 作用域、来源、有效期、删除与授权；该能力当前未实现。
- 如果需要多 Runtime，另设计会话路由、状态盘归属、跨进程互斥和接管；共享数据库本身不够。

## 6. 验收记录模板

每次验收复制下面的空表到发布记录，附日志/实验/审计链接；不要把示例或历史 CI 当新记录。

| 字段 | 填写内容 |
|---|---|
| 代码与组件 | Git SHA、SDK/CLI、Java/Python、镜像摘要、迁移版本 |
| 模型与内容 | 模型 ID、Skill/Tool/Policy 版本、题库版本 |
| 环境 | 测试租户、服务拓扑、状态盘、OMS 实现；不记密钥 |
| 测试项 | 对应清单行、输入、预期、实际、失败复现步骤 |
| 证据 | CI / LangSmith Experiment / OMS 事务与事件审计 / 恢复报告 |
| 决策 | 通过/未通过、负责人、已接受限制、回滚条件 |
